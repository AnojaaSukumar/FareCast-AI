# ✈️ FareCast-AI: Flight Fare Prediction App

FareCast-AI is a machine learning web application that predicts flight fares based on historical data and user-selected flight parameters.

🚀 **Live Demo:** [Launch FareCast-AI on Streamlit Cloud](https://farecast-ai.streamlit.app/)

## 🛠️ Tech Stack
- **Frontend / Framework:** Streamlit
- **Machine Learning:** Scikit-Learn, Joblib, SHAP
- **Data Processing:** Pandas, NumPy
- **Deployment:** Streamlit Community Cloud
